`@cthutool/obsidian-enhancer` is an Obsidian desktop plugin package.

## What It Does

- opens current vocabulary notes in Eudic through deep links
- moves notes based on frontmatter tag hierarchy
- marks notes as reviewed
- advances note status
- exposes plugin settings for vocabulary tag and excluded roots

## Runtime Location

Obsidian client.

## Build

```bash
pnpm --filter @cthutool/obsidian-enhancer build
```
