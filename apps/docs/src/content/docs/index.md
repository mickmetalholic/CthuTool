CthuTool is a pnpm/Turborepo monorepo for local tools, desktop workflows, browser automation, and Codex-facing assets.

This site is a curated map over the repository documentation. It is intentionally not a replacement for source files such as package READMEs or OpenSpec requirements.

## Start Here

- [Repository map](/repo/overview/) explains the main documentation locations.
- [Applications](/applications/) routes to CLI, backend, desktop, web, and browser/auth notes.
- [CthuCodex plugin](/codex/cthu-codex/) covers the repository-managed Codex plugin surface.
- [Capability specs](/capability-specs/) points to current OpenSpec requirements.

## Local Development

```bash
pnpm --filter @cthutool/docs dev
pnpm --filter @cthutool/docs build
```
